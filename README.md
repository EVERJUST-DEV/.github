# EVERJUST-DEV — organisation profile

This repository holds the organisation profile for [@EVERJUST-DEV](https://github.com/EVERJUST-DEV).

The file that actually renders on the organisation page is **[`profile/README.md`](profile/README.md)** —
GitHub reads that specific path, not this one. Edit that file to change what visitors see.

## What lives in this organisation

- **[usesend-email](https://github.com/EVERJUST-DEV/usesend-email)** — useSend for EverJust — self-hosted, multi-tenant transactional email on AWS SES: Terraform infrastructure, an MCP server and docs. Runs mail.everjust.app and replaces Resend across EverJust products.
- **[JustMail](https://github.com/EVERJUST-DEV/JustMail)** *(private)* — JustMail by EVERJUST - self-hosted email, contacts and chat on Odoo 19: three add-ons plus an inbound SES gateway, server-side rules and filters, a unified inbox, and an SPF/DKIM/DMARC setup screen that parses records rather than string-matching them.
- **[justpost-app](https://github.com/EVERJUST-DEV/justpost-app)** *(private)* — JUSTPOST by EVERJUST — social publishing and scheduling, live at justpost.app. Private AGPL-3.0 fork of Postiz with EverJust LinkedIn Pages wiring, AI provider config and deploy-path changes.

## Conventions

- Repository names are lowercase-kebab unless the name is a domain or a proper noun.
- Every live repository carries a description, topics, and a Website link where one exists.
- Archived repositories are prefixed `⛔️ ARCHIVED` and carry a banner at the top of their README.
- Secret scanning and push protection are enabled by default for new repositories here.
